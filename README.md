# LatAm Macro & Sovereign Risk Tracker 

A fully automated R/Shiny application designed for financial analysts, economic consulting firms, and portfolio managers. This dashboard eliminates manual data extraction, providing real-time visualization of sovereign spreads alongside domestic macroeconomic indicators.

## Business Value

Manual aggregation of inflation indices, exchange rates, and bond yields consumes critical analysis time. This application automates the end-to-end data pipeline, delivering a clean, interactive environment to support rapid, data-driven investment decisions.

## Key Analytical Modules

*   **Domestic Macro Monitor:** Tracks exchange rates, inflation indices, and visualizes time-series data using dynamic Plotly charts.
*   **Financial Intermediation & Policy:** Includes dedicated analytical commentary on the performance of financial intermediation activities, alongside analysis of current monetary and fiscal policies.
*   **International Context Hub:** Aggregates top breaking financial news impacting emerging markets.
*   **Expert Investment Recommendations:** Features a curated section displaying current asset allocation strategies and investment recommendations from market experts.
*   **EMBI Spread Analysis:** Filters and compares EMBI sovereign risk data across multiple Latin American nations.

## Technical Architecture

*   **Core Language:** R
*   **Web Framework:** Shiny
*   **Data Visualization:** Plotly
*   **Data Wrangling:** dplyr / tidyr
